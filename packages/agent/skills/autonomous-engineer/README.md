# Autonomous Engineer Skill

`autonomous-engineer` is the repository's outcome-oriented engineering skill. It complements the existing agent tools rather than replacing them.

It is designed for requests such as:

- "Fix this bug and make sure it doesn't come back."
- "Make this feature production-ready."
- "Audit this flow and fix the important problems."
- "Implement this issue and open a PR."

The skill deliberately favors evidence-driven iteration over large speculative edits.

See [`SKILL.md`](./SKILL.md) for the operating contract.
